HEMAT — Anak Kost

Aplikasi web SPA untuk membantu mahasiswa mengelola anggaran harian dengan visualisasi data interaktif menggunakan Chart.js agar keuangan lebih terkontrol dan terencana.

Latar Belakang

Mahasiswa yang tinggal di kost seringkali mengalami kesulitan mengelola keuangan karena ketiadaan pencatatan yang sistematis. Pengeluaran yang tidak terpantau menyebabkan kehabisan uang sebelum akhir bulan. HEMAT hadir sebagai aplikasi web berbasis SPA yang ringan, cepat, dan mudah digunakan untuk membantu mahasiswa mencatat dan memvisualisasikan keuangan harian mereka secara real-time.

Tujuan Project

  • Memudahkan mahasiswa dalam mencatat pemasukan dan pengeluaran harian secara cepat.
  • Memberikan visualisasi grafis yang intuitif untuk memantau pola pengeluaran.
  • Membantu perencanaan anggaran bulanan agar lebih efisien dan terstruktur.

Fitur Utama

  • Input pencatatan pemasukan dan pengeluaran harian dengan kategori
  • Visualisasi chart interaktif (pie chart & bar chart) menggunakan Chart.js
  • Ringkasan anggaran bulanan dengan indikator sisa saldo
  • Riwayat transaksi dengan fitur filter dan pencarian
  • Tampilan responsif yang nyaman digunakan di mobile maupun desktop

Peran & Kontribusi

Saya berperan sebagai Full-Stack Developer & UI Designer dalam project ini. Mulai dari mendesain antarmuka menggunakan Figma, mengembangkan frontend dengan HTML, CSS, dan JavaScript vanilla, hingga mengintegrasikan library Chart.js untuk visualisasi data. Aplikasi dibangun sebagai Single Page Application (SPA) tanpa framework tambahan untuk menjaga performa yang ringan dan cepat.
